# Social Media Platform

A full-stack social media web application built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**.

The platform allows users to create accounts, connect with other users, share posts, and interact with content. It aims to provide a simple social networking experience where users can communicate and share their thoughts with others.

## Features

### 1. User Authentication
- User registration and login.
- Secure password hashing.
- JWT-based authentication.
- Protected routes for authenticated users.
- User logout.

### 2. User Profile
- View user profiles.
- Update profile information.
- Add profile pictures and bio.

### 3. Post Management
- Create and publish posts.
- View posts from other users.
- Edit and delete personal posts.
- Share posts with others.

### 4. Post Interaction
- Like and unlike posts.
- Comment on posts.
- View comments and interactions.

### 5. Follow System
- Follow and unfollow users.
- View followers and following lists.
- Explore posts from followed users.

### 6. Messaging
- Send messages to other users.
- Receive messages.
- Real-time communication.

### 7. Notifications
- Receive notifications for likes, comments, and new followers.
